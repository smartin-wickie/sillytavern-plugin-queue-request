## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored connection strings to popup DOM | From an untrusted chat file |
| connection state at queue time vs spend time | Live ST settings can change between |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-25 | Elevation (spend) | generating on a different model/API than queued | mitigate | Per-item gate immediately before markRunning; pause 'connection' with consent popup; Resume re-runs the gate |
| T-04-26 | Tampering (XSS) | model/api/preset names in popup | mitigate | textContent only; acceptance greps assert no innerHTML in popups.js |
| T-04-27 | Repudiation | silent mass-consent on Continue | mitigate | Only the explicit OK button updates recorded connections; Esc/Keep paused never does |
| T-04-28 | Spoofing | forged connection values in chat file to hide a model change | accept | Values only gate a pause; forged equal values on a changed live connection could skip the prompt; load still requires resume consent |
| T-04-29 | Tampering | in-place preset edit undetected | accept | Documented name-only limit (A2) |
</threat_model>
