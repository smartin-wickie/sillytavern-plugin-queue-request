## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| stored connection strings to DOM | api/model names come from an untrusted chat file |
| popup result to destructive action | Discard removes stored data |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-16 | Tampering (XSS) | popup/dropdown/badge text from stored model/api/preset | mitigate | textContent and createElement only; grep acceptance asserts no innerHTML in popups.js |
| T-04-17 | Tampering | accidental discard on Esc/close | mitigate | Only exact POPUP_RESULT.NEGATIVE discards; anything else is 'dismiss' and keeps items paused |
| T-04-18 | Elevation (spend) | popup opens inside event handler or runs queue before consent | mitigate | Queue is already paused 'restored' before prompt; prompt deferred out of the emit stack and while generating |
| T-04-19 | Denial of service | repeated popups | mitigate | Once-per-load flag in lifecycle |
</threat_model>
