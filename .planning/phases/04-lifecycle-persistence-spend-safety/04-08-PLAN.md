<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| localStorage state mirror to read-only tab store | Untrusted snapshot drives display only |
| read-only tab to chat file | Must never write |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-36 | Tampering | forged state snapshot | mitigate | parseSnapshot validates types, filters reasons to a whitelist, caps items; display only, never persisted or run |
| T-04-37 | Tampering | read-only tab writes queue metadata | mitigate | store.persist/add guarded by readOnly; applySnapshot never persists; unit test asserts no save calls |
| T-04-38 | Elevation (spend) | read-only tab invoked via slash command or wand | mitigate | enqueue/cancelAll/resumeQueue and slash commands refuse when read-only |
| T-04-39 | Tampering (XSS) | snapshot strings in UI | mitigate | Only counts and whitelisted reason codes rendered via textContent; no stored strings reach the DOM |
| T-04-40 | Information disclosure | state mirror contents in localStorage | accept | Same ids/hashes/names as chat_metadata; no prompts; same-origin only |
</threat_model>
