<objective>
## Phase Goal

**As a** SillyTavern user with queued swipes running in the background, **I want to** use native send/swipe/continue/Stop normally **so that** the queue politely waits, never fights my own generation, and never loses a paid-for result.

Purpose: Make the runner's pause a set of reasons (not one boolean), so later plans can add `restored`, `failures`, `connection`, `inspector`, `takeover` without the guard's end-of-generation resume silently clearing them. Reorder `processNext` to park a finished result until idle before re-validating the target (needed for Continue in plan 02). Add the epoch and abort-disposition primitives that chat switch and lifecycle clears (plans 02-03) depend on.

Output: reason-aware runner, `fingerprintStatus`, `store.requeue`, guard with lifecycle hooks and idle watchdog, unit tests. No UI change in this plan.
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| ST event stream to guard/runner | Events from ST core and other extensions drive pause/resume; any extension can emit |
| Runner to chat | A parked result is appended into the live chat |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01 | Tampering | runner append after park | mitigate | Park-then-check order: epoch check, then fingerprintStatus on the live item, then existing appender mesId/is_user checks; a changed target never receives the text |
| T-04-02 | Elevation (spend) | guard end-of-generation resume clearing other pauses | mitigate | resume('native') deletes only that reason; unit test asserts reason isolation |
| T-04-03 | Denial of service | native pause stuck forever | mitigate | Idle watchdog with two consecutive idle polls; interval cleared on stop |
| T-04-04 | Repudiation (spend) | native Stop mistaken for queue cancel | mitigate | Queue never calls stopGeneration; test asserts it; GENERATION_STOPPED treated as foreign |
| T-04-05 | Spoofing | other extension emits GENERATION_* with dryRun false | accept | Worst case is a bounded pause cleared by the watchdog; no spend implication |
</threat_model>
