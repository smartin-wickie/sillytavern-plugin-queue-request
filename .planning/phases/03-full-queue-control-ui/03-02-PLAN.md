## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|------------------|
| T-03-02-01 | Denial of Service | `src/commands.js` `/queueswipe [count]` | mitigate | Clamp math (`room = max - current`) is re-read fresh from `store` on every single invocation, never cached across calls — a scripted `/times N {: /queueswipe :}` loop cannot enqueue past `getMaxQueueSize()`/`HARD_MAX_QUEUE` (RESEARCH Pitfall 4, ASVS V5) |
| T-03-02-02 | Tampering | `src/commands.js` numeric argument parsing | mitigate | `Number(unnamedArg) \|\| 1` with `Math.max(1, ...)`, no `eval`/string-exec of the raw argument; ST's own `SlashCommandArgument` type system handles quoting/type-coercion, not a hand-rolled parser |
| T-03-02-03 | Tampering | `src/wandMenu.js` `#extensionsMenu` DOM insertion | accept | MEDIUM-confidence third-party-sourced markup (RESEARCH Open Question #1); worst case is cosmetic (entries render wrong or don't appear), not a data-safety risk — live-verified in Task 3 before shipping |
| T-03-02-04 | Elevation of Privilege | `src/commands.js`/`src/wandMenu.js` cancel paths | mitigate | Both call the same `cancelAll(store, runner)` helper from 03-01, which only ever invokes `abortOwn()`, never ST's global `stopGeneration()` |
